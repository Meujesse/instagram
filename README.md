# Instagram Meujesse Learning

Publication automatique d'un post par jour sur @meujesse_learning (API officielle Instagram).

- `calendrier.json` : les posts, leur date et leur statut de publication.
- `medias/` : visuels et vidéos servis par GitHub Pages.
- `index.html` : la page « liens en bio ».
- `.github/workflows/publier.yml` : le robot, chaque jour vers 12 h 30.
